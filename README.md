# frases-da-sorte
Esse sistema é uma aplicação simples desenvolvida em Portugol, que roda diretamente no console do Portugol Studio.

O sistema solicita ao usuário o dia do seu aniversário, devendo ser um número inteiro entre 1 e 31, e em resposta retorna a sorte do usuário.

Para cada dia fornecido pelo usuário, uma frase diferente será exibida pelo programa. Por exemplo:

Sistema: Informe o dia do seu aniversário: 10
Resposta do sistema (frase): Sua criatividade é ilimitada, explore novos horizontes.

O sistema deve verificar o número fornecido pelo usuário e dar uma resposta com base nesse número. 

Se o número for entre 1 e 31, o sistema apresentará uma frase da sorte. Caso contrário, será exibida a mensagem 'DIA INVÁLIDO'
